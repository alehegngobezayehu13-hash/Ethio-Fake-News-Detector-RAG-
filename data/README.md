# Ethio Fact Check RAG

A multilingual Retrieval-Augmented Generation (RAG) system
for evidence-based fact checking of Ethiopian information.

## Goal

The system will:

- Collect Ethiopian information using web scraping
- Build a searchable knowledge base
- Retrieve relevant evidence using RAG
- Classify claims as TRUE, FALSE, MISLEADING, or UNVERIFIABLE
- Support multiple Ethiopian languages
- Provide results through a web application
